# v0.2.0-beta.1

Python package version: `0.2.0b1`. Git release tag: `v0.2.0-beta.1`. Install from the tagged source checkout; this update does not publish a new package to PyPI.

This beta replaces the 0.1 scaffold-oriented workflow with explicit validation boundaries from original model graph to compiled ESP32-S3 execution.

## Changes since v0.1.0

- Convert original Keras, SavedModel and ONNX graphs with supplied calibration data and a numerical acceptance gate.
- Generate model-specific C++ inference wrappers, operator resolvers, input/output checks and explicit arena/flash budgets.
- Compile with ESP-IDF 5.5.1, esp-tflite-micro 1.4.1 and ESP-NN 1.4.1.
- Run actual float32 and INT8 ESP32-S3 firmware in pinned Espressif QEMU, with prediction validation and firmware/model/dataset identities in reports.
- Validate serial observations against deployment manifests and produce JSON or HTML reports.
- Exercise Python 3.11/3.12, original-graph ONNX conversion, firmware compilation and emulator success/failure paths in CI.
- Add an evidence-based README, diagrams, a documentation screenshot and a [54-second walkthrough](../walkthrough/v0.2.0-beta.1/README.md) with raw command records.

## Scope and migration

Physical-board validation remains pending. Emulator timing is not hardware performance. STM32 profiles support analysis only; firmware generation rejects unsupported targets. Static resource estimates do not prove that a compiled application fits or runs.

The 0.1 interface is incompatible with this workflow. Follow the [migration guide](../migration-0.2.md) and the current [sine example](../../examples/sine_model/README.md). Quantization requires an original graph, supplied calibration data where required, held-out validation inputs and an explicit error limit. Output paths must be new.

Next development steps: collect real ESP32-S3 serial reports, expand the operator/dtype test matrix with application models, and validate task-level accuracy on representative datasets before promoting the beta to a stable release.
